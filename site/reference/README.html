操作 PPO 源码技术手册

以现有 X5/OrcaGym 按压任务为落点，比较开源任务的物理验收、奖励、控制接口和生效的 PPO 配置。调研日期2026-11-16；具体代码版本见任务卡与证据账本。本地2M续训是独立实验，见 续训说明（本地实验附件，未随手册公开）。

阅读入口 用途
结论与优先级 先确定值得复用的实现
项目生态 区分任务套件、算法库、benchmark和旧项目
任务索引 按任务找到物理条件、奖励、命令
奖励设计 公式、阶段门控、事件与潜在反例
训练配置 生效参数、预算、并行数与入口覆盖
本项目复用方案 可证伪的后续实验与验收边界
覆盖与缺口 检索范围、未知值与源码冲突

本轮筛查15个项目，源码深查8个，建立19条任务记录；奖励记录和配置覆盖的精确计数见coverage.json。这是一份有边界的源码调查，没有运行上游训练，也不宣称穷尽所有项目。

data/ 的五份 JSONL 分别保存项目、任务、奖励、配置、证据。数字缺失用 null，不以常见默认值填空。verified-from-code表示追到所选版本源码；documented-only表示官方资料声明；inferred表示推导；unverified表示尚未核实。任务条目的verified不表示已复现策略成功。
